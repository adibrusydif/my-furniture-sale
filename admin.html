⚙️ One-time GitHub Setup

Your products and images are stored in a GitHub repository.
This setup is needed only once — credentials are saved in your browser.

  1. Create a public GitHub repo (e.g. my-furniture-sale) at github.com/new
  2. Generate a token at github.com/settings/tokens — give it Contents: Read & Write on your repo
  3. Fill in the fields below and click Save & Connect
This is saved only in your browser — never sent anywhere else.
